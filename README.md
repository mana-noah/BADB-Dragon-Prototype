# 《劫火》実戦闘プロトタイプ v0.1

NOAHの既存コマンド選択式バトルを土台に、神獣龍イグニス＝ヴァルガとの戦闘を試すためのブラウザ用プロトタイプです。

## 起動方法
- `index.html` をブラウザで開きます。
- GitHub Pagesを利用する場合は、リポジトリの Settings → Pages で公開設定を行います（まだ公開設定がされているとは限りません）。

## 試すこと
1. 「感知」で龍の感情を読む。
2. 共鳴値を20以上にし、共鳴攻撃を選ぶ。
3. 感知後の共鳴攻撃で鎮静が進むかを試す。
4. 通常攻撃を続けた場合と、様子見を使った場合を比べる。
5. 龍のHPだけでは勝利にならず、鎮静進行3回で勝利することを確認する。

## v0.1の扱い
- 感情・火山活動・ダメージ・鎮静の数値はプレイテスト用の仮設定です。
- 感知、通常攻撃、共鳴攻撃、オトモン連携、様子見の既存仕様を優先しています。
- 共鳴攻撃の倍率・閾値は今回共有された仕様を仮採用しています。大共鳴攻撃の閾値など、原資料に不一致がある箇所は正式確定ではありません。
- 感知を繰り返す戦法が強すぎる可能性があります。現行の「感知ターンは敵が攻撃しない」という仕様を保ったまま検証し、問題があれば設計側へ戻します。
- このプロトタイプはNOAH本体ではなく、`mana-noah/BADB-Dragon-Prototype` 専用です。
